#+TITLE: pad
#+DESCRIPTION: A notepad at every URL
#+OPTIONS: ^:{}

A notepad at every URL: open =/anything=, type, and it saves. The first segment of a path is its root; whoever saves under a root first sets its password, which guards reading and writing every pad under it. Pads are encrypted in the browser with keys from that password: the server never sees it, a pad's text or the path under the root. Self-hosted as one Docker image and one SQLite file, for amd64 and arm64; the author's runs at [[https://pad.nassu.online][pad.nassu.online]].
